# Data Structures & Algorithms

Coursework and implementations from my Data Structures and Algorithms class, built around a set of core computer science outcomes: abstraction, classic ADTs (lists, stacks, queues, trees, graphs), sorting/searching, algorithmic efficiency, and secure programming practices.

## Course Outcomes

This repo is organized to demonstrate the following:

1. **Data Abstraction** — using abstraction as the fundamental building block of programming.
2. **Lists** — an abstract data type built with class object definitions, implemented in both static (array-based) and dynamic (linked) representations.
3. **Stacks** — an abstract data type built with class object definitions, implemented in both static and dynamic representations.
4. **Queues & Priority Queues** — abstract data types implemented in both static and dynamic representations.
5. **Trees** — an abstract data type with applications of various tree types, implemented using recursive techniques.
6. **Graphs** — an abstract data type with applications of Breadth-First Search, Depth-First Search, and shortest-path algorithms.
7. **Sorting & Searching** — advanced sorting and searching techniques, evaluated and applied.
8. **Algorithm Efficiency** — analysis and comparison of algorithm efficiency (time/space complexity).
9. **Secure Programming** — analysis and application of secure coding issues and techniques.
